TL;DR: VidMatcher personalizes video generation from a reference image by matching features between a reference branch and a generation branch, preserving identity while keeping motion natural and prompt-aligned.

Overview

We introduce VidMatcher, a video personalization framework designed to generate videos of a target subject from a reference image while following a text prompt. Unlike prior approaches that rely heavily on fine-tuning yet still lose identity details, VidMatcher combines lightweight model adaptation with a cross-branch feature warping strategy. During generation, a reference branch and a generation branch run in parallel, and attention-based correspondences are used to warp reference features into the generated video, controlled by foreground and consistency masks. This approach preserves motion coherence while injecting fine-grained appearance cues, enabling more faithful and temporally stable subject-driven video generation.

Our approach

(a): Given a few images of the subject, VidMatcher coarsely adapt the subject's appearance to the video diffusion model utilizing LoRA.

(b): After coarse appearance alignment, VidMatcher further refine the appearance under parallel reference, generation branches. By utilizing token-level correspondences, reference appearance features are effectively warped and injected to the generation branch for enhancing appearance consistency.

VidMatcher adopts a coarse-to-fine strategy: first, lightly adapting the model with a subject embedding and K/V/O-only LoRA to encode coarse identity; then, during inference, running a reference and generation branch in parallel and injecting fine appearance via semantic correspondence–guided value warping with masking. This design preserves temporal motion while accurately transferring high-frequency subject details.

Motivation

Text-to-video diffusion models can produce high-quality and temporally stable videos, yet they still struggle to maintain consistent subject identity when guided by reference images. While prior approaches rely on parameter updates or auxiliary training signals, they do not leverage the model’s intrinsic ability to represent semantic relationships across frames. Our observation is that transformer-based video diffusion models already encode meaningful cross-frame correspondences, suggesting that personalization can be achieved by exploiting these internal signals rather than modifying the model extensively.

Comparison of feature matching behaviors across representation types. Intermediate features fail to produce meaningful alignment, raw Query–Key features suffer from positional bias due to RoPE, and only RoPE-free Query–Key features yield accurate subject-aware correspondence suitable for feature transfer.
Layer-wise correspondence evaluation. RoPE-free Query–Key features achieve the highest matching reliability, with the strongest alignment observed in mid-level transformer layers, particularly layer 12.

Qualitative comparison

We evaluate VidMatcher qualitatively and observe clearer identity consistency across frames, while preserving natural motion and alignment with the input prompt.

Quantitative comparison

We report CLIP/DINO and VBench scores to show that VidMatcher not only preserves identity effectively, but also maintains overall video quality and temporal coherence.

Comparison of identity preservation

VidMatcher achieves the strongest identity preservation across all baselines while maintaining comparable text alignment, and does so without large-scale finetuning—showing that efficient personalization can still deliver high visual fidelity.

Ablation study

Component-level evaluation

The ablation compares coarse adaptation, value warping, and masked warping. Coarse adaptation offers a stable baseline but misses fine details. Value warping restores detailed appearance, though sometimes introduces artifacts. Masking filters unreliable transfers, yielding the best balance between identity fidelity and text alignment.

Conclusion

VidMatcher tackles video personalization by combining lightweight model adaptation with correspondence-guided appearance transfer. Instead of relying solely on fine-tuning, it matches reference and generated features during denoising and selectively injects appearance information using warping and masking. This design preserves motion while maintaining fine identity details, achieving better consistency than prior methods.
